# 安卓高刷工具

**安卓高刷工具**是一款 Android 全局高刷新率管理工具。可自定义屏幕刷新率，并在已适配的设备上开启屏幕支持的最高刷新率，突破部分应用默认刷新率限制。

- **全局高刷**：一键应用自定义刷新率，支持已适配设备的全局高刷控制。
- **自定义档位**：根据设备支持情况选择不同刷新率。
- **悬浮监控**：实时查看屏幕 Hz，可自由拖动、调整透明度。
- **恢复自动**：一键恢复系统自动刷新率模式。
- **简洁易用**：支持简体中文、English 和深色模式。

目前已在部分 **vivo、OPPO** 设备上完成测试，后续将持续适配更多安卓品牌及机型。不同系统和固件的支持情况可能有所区别。
