# 安卓高刷工具

一款简洁的 Android 屏幕刷新率管理工具，可查看当前刷新率、在兼容设备上尝试启用高刷、恢复自动模式，并提供悬浮 Hz 监控。

目前重点适配 **vivo、OPPO**，已在部分机型上完成测试；后续将持续适配其他安卓品牌。不同机型、系统版本的支持情况可能有所不同。

支持简体中文、English 和深色模式。

**下载：** 前往 [Releases](../../releases) 获取 APK。  
**反馈：** 欢迎通过 [Issues](../../issues) 提交机型、系统版本和问题描述。

> 高刷新率可能增加耗电和发热；屏幕 Hz 不等于应用或游戏 FPS。

第三方技术参考与许可说明见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
